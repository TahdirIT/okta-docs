# منصة أوكتا التعليمية

## نظرة عامة

منصة أوكتا هي منصة تعليمية شاملة مصممة لإدارة المدارس والمجمعات التعليمية بكفاءة عالية. توفر المنصة مجموعة متكاملة من الخدمات التي تغطي جميع جوانب العملية التعليمية والإدارية، بدءاً من إدارة الطلاب والمعلمين وصولاً إلى التقارير والتحليلات المتقدمة.

> للصورة الشاملة عبر المستودعات (المنصة، الشركاء، تطبيق الجوال، التطبيقات المثبَّتة) راجع [`CLAUDE.md`](../CLAUDE.md) وطبقة المراجع [`claude/`](../claude/).

### الخدمات الأساسية

للاطلاع على فهرس الخدمات وتوثيق كل خدمة، راجع [فهرس الخدمات](services/README.md). يميّز الفهرس بين الخدمات الجوهرية داخل `okta-web` والقدرات التي تُقدَّم كتطبيقات مثبَّتة.

## الفئات المستهدفة

المنصة تخدم الكيانات التعليمية بأنواعها (معلم فردي، مدرسة، مجمع، كلية، جامعة، معهد، أكاديمية، شركة تعليمية) والمستخدمين المرتبطين بها (مدراء، إداريون، معلمون، طلاب، أولياء أمور). للتفاصيل راجع [الأدوار والكيانات](roles-and-entities/README.md) و[أنواع الكيانات](roles-and-entities/tenants.md).

## الأدوار والكيانات والعلاقات

لأنواع الكيانات (Tenants) وأدوار المستخدم النهائي والعلاقات بينها، راجع
[الأدوار والكيانات](roles-and-entities/README.md).

### ميزات الاشتراك

- **اشتراكات مرنة**: اشتراكات سنوية أو شهرية
- **تخصيص الخدمات**: اختيار الخدمات المطلوبة
- **تجربة متجر التطبيقات**: تجربة اشتراك مشابهة لمتاجر التطبيقات — التطبيقات تُطوَّر عبر [منصة الشراكات](partner-platform.md) وتُثبَّت لكل جهة

## الستايل والهوية البصرية

للاطلاع على تفاصيل معايير الهوية والتصميم، راجع [معايير الهوية والتصميم](tech-standards/design-standards.md) وبقية [المعايير التقنية](tech-standards/README.md).

## تطوير التطبيقات المثبَّتة (Installed Applications)

دليل للمطوّرين حول كيفية تطوير صفحات التطبيق المثبَّت وظهورها في **okta-web** (سطح المنصة) وفي **okta-app** (سطح العميل): راجع [دليل تطوير التطبيقات](app-development/README.md) (بالإنجليزية). توجد ثلاثة تطبيقات مثبَّتة حقيقية في مساحة العمل: `okta-smart-timetable` (الجدول الذكي)، `okta-exams` (الاختبارات النهائية)، `okta-hdor` (حضور).

# اوكتا الجدول الذكي (okta-smart-timetable)

تطبيق مثبَّت (embedded) يولّد جداول المدرسة الدراسية آلياً عبر محرّك قيود
(backtracking) بمساعدة وكيل الذكاء الاصطناعي للمنصة، ثم يدير العمليات اليومية
للصفوف (الحضور، اقتراح/إسناد المعلّم البديل).

> هذه الصفحة ملخّص؛ المصدر الكنسي للتفاصيل هو مستودع التطبيق
> (`okta-smart-timetable`) وملف `CLAUDE.md` فيه. العقد العام للتطبيقات المثبَّتة:
> [`claude/installed-apps.md`](../../../claude/installed-apps.md).

## أبرز الخصائص

- توليد/تحرير الجداول عبر معالج (BuilderWizard) ولوحة اليوم الدراسي (DailyBoard).
- نطاقات قراءة فقط على بيانات التعليم (الصفوف، الشعب، المواد، الطلاب، الموظفون…).
- إشعار `okta-smart-timetable.substitute.assigned` عند إسناد معلّم بديل.
- يستخدم مولّد الصفحات `php artisan okta-smart-timetable:make-page` للصفحات المتوافقة مع الـ policy.

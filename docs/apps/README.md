# التطبيقات الشريكة (Partner / Installed Apps)

كل ما يخصّ التطبيقات التي تُبنى عبر **منصّة الشراكات** (`okta-partners`)
وتُثبَّت لكل جهة، فتظهر **بسطحين** من تثبيتٍ واحد: داخل **okta-web** (واجهة
المنصّة) وداخل **okta-app** (واجهة العميل). هنا نظرة المنصّة ودليل تطوير التطبيق؛
توثيق منتج/بيانات كل تطبيق مثبَّت يعيش في مستودعه الخاص.

> **العقد التقني وآلية النشر/التثبيت** (manifest، النطاقات، العزل، السطحان،
> sandbox→prod) في طبقة المراجع:
> [`reference/partners.md`](../reference/partners.md) ·
> [`reference/installed-apps.md`](../reference/installed-apps.md) ·
> [`reference/deployment.md`](../reference/deployment.md).

## منصّة الشراكات (okta-partners)

منصّة مستقلة مخصّصة للشركاء والتكاملات الخارجية. بعد الطلب والموافقة، يحصل
الشريك على واجهة برمجية قائمة على الصلاحيات (Scopes بصيغة
`<feature>.<resource>.<action>`، قراءة/كتابة فقط) لبناء تكامله.

**رحلة التطبيق:** يُؤلَّف ويُدار إصداراته في `okta-partners` (أنواع التكامل:
**embedded** يشحن ككود داخل المنصّة، **external** مستضاف خارجياً،
**notification** مزوّد إشعارات، **payment** مزوّد دفع)، يمرّ بمراجعة واعتماد،
يُجرَّب على **sandbox**، ثم يُنشر إلى **production** عبر الجسر إلى `okta-web`.
التطبيق المثبَّت يظهر بسطحين: واجهة المنصّة (okta-web) وواجهة الجوال (okta-app).

## دليل التطوير

- [**دليل تطوير التطبيقات**](./development/README.md) — كيف تُطوَّر صفحات التطبيق
  المثبَّت وتظهر في `okta-web` (سطح المنصّة) و`okta-app` (سطح العميل)، وعقد
  الوصول للبيانات والأمان ومرجع الـ manifest (إنجليزي).

## توثيق منتج/بيانات كل تطبيق

توثيق كل تطبيق مثبَّت (نماذجه، تدفّقاته، شاشاته) يعيش في **مستودعه الخاص** تحت
`docs/`، لأنه يتطوّر مع كود التطبيق. المصدر الكنسي لكل تطبيق هو مستودعه وملف
`CLAUDE.md`/`README.md` فيه.

# التطبيقات الشريكة (Partner / Installed Apps)

كل ما يخصّ التطبيقات التي تُبنى عبر **منصّة الشراكات** (`okta-partners`)
وتُثبَّت لكل جهة داخل **okta-web** وتظهر في **okta-app**: نظرة المنصّة، دليل
تطوير التطبيق، وتوثيق منتج كل تطبيق مثبَّت.

> **العقد التقني وآلية النشر/التثبيت** (manifest، النطاقات، العزل، السطحان،

## منصّة الشراكات (okta-partners)

منصّة مستقلة مخصّصة للشركاء والتكاملات الخارجية. بعد الطلب والموافقة، يحصل
الشريك على واجهة برمجية قائمة على الصلاحيات (Scopes بصيغة
`<feature>.<resource>.<action>`، قراءة/كتابة فقط) لبناء تكامله.

**رحلة التطبيق:** يُؤلَّف ويُدار إصداراته في `okta-partners` (أنواع التكامل:
**embedded** يشحن ككود داخل المنصّة، **external** مستضاف خارجياً،
**notification** مزوّد إشعارات، **payment** مزوّد دفع)، يمرّ بمراجعة واعتماد،
يُجرَّب على **sandbox**، ثم يُنشر إلى **production** عبر الجسر إلى `okta-web`.
التطبيق المثبَّت يظهر بسطحين: واجهة المنصّة (okta-web) وواجهة الجوال (okta-app).

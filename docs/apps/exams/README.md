# اوكتا الاختبارات النهائية (okta-exams)

تطبيق مثبَّت (embedded) يدير دورة حياة الاختبارات النهائية: فترات الاختبار،
اللجان وتوزيع المقاعد، المراقبون، حضور الطلبة، وحزمة تقارير قابلة للطباعة.
مدفوع (اشتراك شهري/سنوي)، ويُثبَّت لكل جهة من المتجر.

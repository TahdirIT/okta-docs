# خدمة OTP (رموز التحقق)

توثيق خدمة **رموز التحقق لمرة واحدة (OTP)** في `okta-web`: إرسال رمز عبر سلسلة
قنوات (واتساب → SMS → بريد) والتحقق منه، مع حدود المعدّل والأمان. تقابلها
`App\Services\Otp\*`.

> **ملاحظة:** هذا التوثيق **مفاهيمي بالدرجة الأولى** (يصف السلوك المقترح للخدمة)؛
> راجع الكود في `okta-web` للتفاصيل المُنفَّذة الدقيقة.

# خدمة رمز التحقق (OTP Service) — دليل مفاهيمي

> 📎 خلفية مفاهيمية للمفاهيم العامة. المرجع المطابق للتنفيذ هو
> [`../README.md`](../README.md).

هذا المجلد يغطّي مفاهيم OTP العامة:

- تدفق طلب الرمز وإرساله (Email/SMS/قنوات حسب التكامل).
- التحقق من الرمز وربطه بسياق (Purpose/Action).
- سياسات الصلاحية (TTL) وحدود الطلبات ومحاولات التحقق.

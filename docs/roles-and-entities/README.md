# الأدوار والكيانات والعلاقات (roles-and-entities)

المرجع الموحّد لـ**أنواع الكيانات (Tenants)**، و**أدوار المستخدم النهائي
(End-Users)**، و**العلاقات** بينها (احتواء، ملكية، إدارة، متابعة، اشتقاق
بالصلاحيات). هذا المجلد هو **مصدر الحقيقة** لأسماء الأنواع/الأدوار وترتيبها،
وتعتمد عليه خدمات أخرى (التسجيل، إدارة الدول، RBAC، الإشعارات…).

## المحتوى

| الملف | يغطّي |
|---|---|
| [`tenants.md`](tenants.md) | أنواع الكيانات (نوع الحساب / Tenant) وترتيبها المرجعي. |

| [`role-hierarchy.md`](role-hierarchy.md) | خريطة العلاقات «متبوع → تابع»: احتواء الكيانات، إدارة الجهة لمستخدميها، المتابعة، واشتقاق الأدوار بالصلاحيات. |
| [`tech/`](tech/README.md) | **الطبقة التقنية**: كيف تُترجَم الأنواع/الأدوار/العلاقات إلى جداول ونماذج وmiddleware وجسور عبر `okta-web`/`okta-partners`/`okta-app` وتطبيقات Embedded. |

## مفاهيم سريعة

- **الكيان (Tenant / نوع الحساب)**: الجهة المشتركة في المنصة (شركة تعليمية،
  مجمع، جامعة، كلية، مدرسة إدارية، معهد، أكاديمية، معلم فردي).
- **مسؤول الحساب**: المالك المباشر للجهة؛ ومنه تُشتقّ أدوار أخرى بتفويض جزء من
  صلاحياته.
- **العلاقات**: حاويات تحتوي جهات أصغر، وجهات تشغيلية تدير مستخدميها، إضافةً إلى
  علاقات داخل الأدوار (ولي أمر ← طالب) واشتقاق بالصلاحيات.

> ملاحظة للمحرّرين: تغيير أسماء الأنواع/الأدوار أو ترتيبها قد **يكسر** افتراضات في
> الخدمات المعتمدة على هذا المرجع — راجع الإشارات إلى
> `docs/roles-and-entities/` قبل التعديل وعامِل التغيير كـ breaking.

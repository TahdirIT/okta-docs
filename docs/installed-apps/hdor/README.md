# اوكتا حضور (okta-hdor)

تطبيق مثبَّت (embedded) يسجّل حضور/انصراف الطلاب، يرصد الغياب عند حدّ يومي،
يدير طلبات الاستئذان، ويُشعر أولياء الأمور. يلتقط الحضور عبر الجوال
(باركود/هوية وطنية/بصمة/وجه/NFC/UHF-RFID)، ويفوّض كل المراسلة إلى المنصة.

> **مبدئي.** التوثيق التفصيلي في مستودع التطبيق (`okta-hdor`) — بما فيه
> `NOTIFICATIONS.md` — وملف `CLAUDE.md` فيه. العقد العام للتطبيقات المثبَّتة:
> [`claude/installed-apps.md`](../../../claude/installed-apps.md).

## أبرز الخصائص

- سطح جوال حقيقي (`mobile.supported: true`) — الوحيد بين التطبيقات الثلاثة.
- ٧ أنواع إشعارات (حضور/انصراف/غياب/عذر + استئذان)، بقنوات in_app/whatsapp/push.
- مجدول يومي (`okta-hdor.daily-closure`) + أوامر console للإقفال والتقارير.
- ويبهوكس صادرة موقَّعة مع واجهة إدارة، ونطاقات قراءة/كتابة على الحضور والتقارير.

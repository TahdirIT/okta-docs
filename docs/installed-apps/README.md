# التطبيقات المثبَّتة (Installed Apps)

توثيق **منتجي** للتطبيقات الشريكة التي تُثبَّت لكل جهة من المتجر. هذه ليست
خدمات جوهرية داخل `okta-web` — كل تطبيق يعيش في مستودعه الخاص، ويُؤلَّف ويُنشر
عبر `okta-partners`، ويظهر بسطحين (منصة + جوال).

> **العقد التقني وآلية التثبيت** (manifest، النطاقات، العزل، السطحان،
> sandbox→prod) موثَّقة مرة واحدة في طبقة المراجع:
> [`claude/installed-apps.md`](../../claude/installed-apps.md) و
> [`claude/deployment.md`](../../claude/deployment.md). هذا المجلد يغطّي كل تطبيق
> من منظور المنتج (القدرات، الأدوار، التدفقات).

# أرشيف برومبتات البناء (Historical build prompts)

> ⚠️ **هذا المجلد أرشيف وليس توثيقاً للحالة الراهنة.**

الملفات هنا هي **برومبتات** كُتبت لتوجيه بناء ميزات المنصة في وقتها (تسجيل
الكيانات، إدارة الاختبارات، الإشعارات، …). بعضها نُفِّذ وتغيّر الكود بعده،
وبعضها لم يُنفَّذ إطلاقاً — فلا تعتمد عليها كمرجع لكيفية عمل النظام اليوم.

للحالة الراهنة ارجع إلى:

- طبقة المراجع [`claude/`](../../claude/) — الصورة الشاملة عبر المستودعات.
- توثيق الخدمات [`../services/`](../services/) — تفاصيل كل خدمة.
- دليل تطوير التطبيقات [`../app-development/`](../app-development/README.md).
- ملف `CLAUDE.md` داخل كل مستودع كود.

المجلد [`old/`](./old/) يضم مراجع أقدم من ذلك.

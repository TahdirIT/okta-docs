# okta-docs — مركز توثيق منصّة أوكتا

مستودع التوثيق ومصدر المعايير لمنتج **okta** التعليمي المتكامل. لا يحوي كوداً —
توثيق فقط. المنتج منتَج واحد موزَّع على عدّة مستودعات: منصّة أساسية (`okta-web`)
تملك البيانات وتُصدِّر الخدمات، ومنصّة شركاء (`okta-partners`) تُؤلَّف وتُثبَّت من
خلالها التطبيقات في الأساس، وعميل Flutter (`okta-app`) يعرض لكل جهة تطبيقاتها
المثبَّتة، وتطبيقات مثبَّتة يعيش كلٌّ منها في مستودعه.

> **نقطة الدخول للوكلاء (AI):** [`CLAUDE.md`](./CLAUDE.md) هو الخريطة الموجَّهة
> لـ Claude/Cursor. هذا الـ README فهرس بشري لكامل المستودع.

## قواعد التحرير

- **لا كود** في هذا المستودع — توثيق فقط.
- طبقة `docs/` عربية أساساً (Markdown صديق للـ RTL)؛ تغيير أي **معيار** قد **يكسر**
  المستودعات المستهلِكة — عامِله كتغيير كاسر ووثّق مسار الترحيل.
- طبقة `claude/` إنجليزية وتصف المنتج المتكامل — استخدم روابط نسبية وتأكّد من أنها
  تُحَل.
- لا تنشئ ملفات توثيق في جذر المستودع (ضعها تحت `docs/` أو `claude/`)، ولا تودِع
  مسودّات مؤقتة. عند إضافة معيار حدِّث [فهرس المعايير](./docs/tech-standards/README.md)،
  وعند إضافة خدمة حدِّث [فهرس الخدمات](./docs/services/README.md) واتبع تخطيطه المعتمد.

> لكل مستودع كود ملف `CLAUDE.md` خاص به بتفاصيله الداخلية؛ استخدم هذا المركز
> للصورة الشاملة عبر المستودعات.
